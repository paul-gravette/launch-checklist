# Launch Checklist

A practical **distribution and launch** playbook for founders, CEOs, and PE portfolio teams — so “we shipped” actually means “someone found it.”

## Who this is for

- Founders launching a product, waitlist, or fundraise narrative
- CEOs and operators shipping a new offer inside an existing company
- PE portfolio teams running a relaunch or market entry without a big agency deck

## What’s inside

| Path | Use it for |
|------|------------|
| [`phases/pre-launch.md`](phases/pre-launch.md) | Audience, offer, and proof before go-live |
| [`phases/launch-week.md`](phases/launch-week.md) | Day-by-day launch week cadence |
| [`phases/post-launch.md`](phases/post-launch.md) | Follow-through so momentum doesn’t die on day 8 |
| [`templates/channel-map.md`](templates/channel-map.md) | Map owned / earned / paid channels with owners |
| [`templates/go-to-market-brief.md`](templates/go-to-market-brief.md) | One-page GTM brief before the campaign calendar |

## How to use

1. Start with the GTM brief, then pre-launch — don’t skip proof and audience.
2. Assign one owner per channel (no shared ownership).
3. Run launch week as a checklist, not a vibe.
4. Book the post-launch review on the calendar *before* you launch.
